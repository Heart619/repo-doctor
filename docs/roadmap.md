Repo Doctor uses GitHub issues and milestones for roadmap tracking. This page summarizes the current direction and links to the public planning issues.

## Priorities

- Keep checks local-first and explainable.
- Prefer actionable findings over broad quality scoring.
- Add tests before changing scanner, reporter, config, or CLI behavior.
- Keep release work visible through issues, pull requests, CI, changelog entries, and GitHub releases.
