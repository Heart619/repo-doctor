Repo Doctor
Usage Workflows Reference

CLI and GitHub Action

Repository health checks for open source maintainers.

Repo Doctor audits README guidance, license, tests, CI, templates, security policy, changelog, package metadata, and SARIF output readiness.

GitHub Releases

Usage

Local scan

repo-doctor . --markdown

CI gate

repo-doctor . --fail-on medium

SARIF output

repo-doctor . --sarif > repo-doctor.sarif

Maintainer Workflows

Use Repo Doctor during issue triage, pull request review, and release readiness checks. It keeps repository maintenance signals visible and repeatable.

  • Detect missing repository basics before release.
  • Publish Markdown summaries in GitHub Actions.
  • Export SARIF for code scanning integrations.
  • Dogfood maintenance tools on every pull request.
